# Healthcare Operations & Financial Overview

## Introduction
This project analyzes **54,966 patient admission records** to evaluate **hospital operational efficiency, patient throughput, and financial performance**. By combining **Python** for data cleaning, **SQL** for database querying, and **Power BI** for interactive visualization, the analysis delivers executive insights to reduce Average Length of Stay (ALOS), optimize bed and staffing allocation, and streamline insurance reimbursement cycles across clinical departments.

## 🛠️ Skill Showcase

| Tech Stack | Core Skills Demonstrated | Practical Application |
| :--- | :--- | :--- |
| **Python** | Pandas, Data Cleaning, Datetime Wrangling | Audited and cleaned **54,966 patient records**[cite: 3, 4]; derived patient Length of Stay. |
| **SQL** | Window Functions, CTEs, Aggregations | Evaluated physician billing performance, payer mix share, and revenue trends. |
| **Power BI & DAX** | Data Modeling, Time Intelligence, Measure Design | Built dynamic MoM revenue growth KPIs, ALOS tracking, and interactive dashboards. |
| **Healthcare Operations** | Revenue Cycle Management (RCM), Capacity Planning | Formulated 5 strategic recommendations to optimize bed allocation and lower ALOS. |
